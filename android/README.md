# 晚安成电自动打卡助手

一个帮你自动完成「晚安成电」每日打卡的 Android 应用：登录一次后，应用会在每天打卡窗口内**自动完成打卡**——不需要保持应用打开，也不需要后台常驻。

> ⚠️ 本应用为个人学习项目，**非官方工具**，与学校无任何关联。使用前请务必阅读文末的「免责声明」。

## ✨ 功能特性

| 功能 | 说明 |
| --- | --- |
| 一次登录 | 内置学校统一身份认证页面，登录一次自动保存会话 |
| 定时自动打卡 | 每天在打卡窗口内自动执行（默认 21:05–23:30，自动同步服务端窗口），失败自动重试 |
| 无需后台常驻 | 使用系统级精确闹钟（AlarmManager），应用被清理后到点仍会执行；开机自动恢复 |
| 结果通知 | 每次执行结果以系统通知反馈，应用内「运行日志」可查看历史记录 |
| 脚本定位 | 默认使用服务端下发的本账号打卡点；支持地图选点 / 使用当前位置 / 手动输入 |
| 深浅主题 | 一键切换深色 / 浅色模式 |
| 服务开关 | 随时暂停或恢复自动打卡 |

## 📲 安装

1. 下载并安装 APK（首次安装需在系统设置中允许「安装未知来源应用」）
2. 系统要求：**Android 8.0 及以上**

## 🚀 使用步骤

1. **登录**：打开应用 → 点击「登录账号」→ 在页面内完成学校统一身份认证（成功后会自动返回）
2. **授权**：点击左上角 ☰ →「权限检查」，按引导依次授予：
   - 精确闹钟权限
   - 电池优化白名单
   - 国产系统还需在系统设置中允许「自启动」「后台运行」
3. **保持服务开启**：主界面「后台自动打卡服务」开关保持 ON
4. **验证**：点 ☰ →「测试打卡」确认流程正常
5. 完成，之后每天自动打卡，无需任何操作

## ❓ 常见问题

**到点没有自动打卡？**
- 依次检查：通知权限、精确闹钟权限、电池优化白名单（☰ →「权限检查」）
- 若曾「强行停止」过应用，系统会清除所有闹钟 → 打开一次应用即可自动恢复
- 国产系统请确认允许了「自启动」

**如何修改打卡位置？**
☰ →「脚本定位」：可在地图上点选（拖动微调）、使用手机当前位置、或手动输入坐标。

**打卡时间窗口变了？**
每次登录与打卡时应用都会自动同步服务端的最新时间窗口，无需手动维护（☰ →「调整时间窗口」可查看或手动同步）。

**登录过期了怎么办？**
重新点一次「登录账号」即可，其余配置与记录都会保留。

## 🛠️ 从源码构建

环境要求：JDK 17+（推荐 21）、Android SDK Platform 35。

```bash
cd android
./gradlew assembleDebug
```

产物位于 `android/app/build/outputs/apk/debug/app-debug.apk`；也可用 Android Studio 直接打开 `android/` 目录进行运行与调试。
